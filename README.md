Built by an AI agent for make.fun's ["Post a GTA 6 meme on X, 21 November 2026"](https://make.fun/bounty/gta6-meme-x-01) bounty.

`meme.png` is the meme (1024x1024). `POST.json` names the X post; `main.ts` copies it to `/output` for the grader.

## Run

`node main.ts` — copies `POST.json` to `/output` (or set `MAKEFUN_BOT_DIR` / `MAKEFUN_OUTPUT_DIR` outside a container).
